# SkoleBibliotek OOP Wiki

This wiki documents the C# and object-oriented programming topics relevant to the SkoleBibliotek project and the TEC school curriculum.

## Purpose

This repository is meant to support learning, reflection, and oral exam preparation. It explains the theory behind the project and connects it to the actual code and structure used in the school assignment.
