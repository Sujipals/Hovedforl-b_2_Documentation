# Project Overview

## Purpose of the project

The SkoleBibliotek project is used to learn object-oriented programming in C#. It models a small library system where different entities such as books, borrowers, and library rules interact with each other.

## Domain model

The project usually includes concepts such as:

- Book
- Borrower
- Library
- Borrowing rules
- Loan status
- Exceptions for invalid operations

## Why this project is useful

It gives students a realistic domain where they can apply:

- classes and objects
- fields and properties
- access modifiers
- collections
- exception handling
- inheritance and polymorphism
- code organization and refactoring

## Relationship between classes

A typical design uses relationships like:

- one Library contains many Books
- one Borrower can borrow several Books
- one Book has a current status or condition

This helps students understand how objects collaborate in a program.

## School learning goals connected to the project

This project supports learning about:

- object-oriented design
- encapsulation
- modeling real-world concepts
- implementing business rules in code
- testing logic with exceptions and validation
- maintaining a clean class structure
