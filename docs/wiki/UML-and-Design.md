# UML and Software Design

## UML

Unified Modeling Language (UML) is used to describe classes and relationships in a visual way.

## Typical diagram types

- class diagram
- use case diagram
- sequence diagram

## Example class diagram idea

```text
+-------------------+
| Book              |
+-------------------+
| - title           |
| - author          |
+-------------------+
| + Borrow()        |
+-------------------+
```

## Design principles

- cohesion: parts should belong together
- loose coupling: classes should depend on abstractions instead of tight implementation details
- readability: code should be easy to follow

## Exam note

A good answer explains that object-oriented design aims to model the domain clearly and reduce complexity.
